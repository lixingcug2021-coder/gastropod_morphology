Replace every bracketed field with actual information. These templates are not claims that deposition or publication has occurred. Check that all manuscript data/code are covered before using “all”.

> The datasets underlying the analyses associated with Fig. 1, Fig. 3, Supplementary Fig. 3 and Supplementary Fig. 7 are available in [REPOSITORY NAME] at [DATA DOI OR STABLE ACCESS URL]. The deposited files include the paired analytical values and their variable definitions. [DESCRIBE ACCESS TO UNDERLYING MEASUREMENTS, ORIGINAL SOURCES AND THE REMAINING DATA SUPPORTING THE STUDY.] [IF A SOURCE DATA FILE IS ACTUALLY SUBMITTED: Source data are provided with this paper.]

If data and code are archived together, the same archive DOI can identify the combined deposit. If reused datasets are subject to restrictions, state the actual access conditions and cite their source records.

## During peer review

Use actual reviewer-access links or the submission system's uploaded code/data files if the public archive is not yet available. Do not insert a DOI that has not been issued or claim that a private GitHub repository is accessible to reviewers merely because its URL is supplied. Match any anonymization requirements selected for the submission.

## Suggested archive citation structure

> [AUTHOR(S)]. [TITLE OF DATA/CODE DEPOSIT] (Version [VERSION]). [REPOSITORY] [FULL DOI URL] ([YEAR]).

Do not use the manuscript article DOI as a substitute for the software/data version DOI. Add the article DOI separately when available.

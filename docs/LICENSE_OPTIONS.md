This draft does not assign a license. Public visibility alone does not provide a clear reuse license. Confirm that the authors hold the necessary rights, including for any third-party data.

- Code: consider an appropriate OSI-approved software license; MIT is one commonly used option for small analysis scripts. A final LICENSE file needs the correct copyright-holder information.
- Data and documentation: consider a suitable data/content license, such as CC BY 4.0 where appropriate. State its scope separately from the code license, for example in DATA_LICENSE.md.
- Retain existing third-party licensing and attribution requirements. Do not apply a new license to data for which the authors lack that authority.

After choosing, place the actual license text(s) in the repository root, state their scope in README.md, and record the code license identifier in the completed CITATION.cff. Update the Code availability statement accordingly.
